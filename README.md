# Презентация «AI-Оператор»

Живая версия: https://yasko-preza-1001.vercel.app (`/` — первая часть, `/rest` — вторая часть с продажей).

## Как открыть у себя

```bash
python3 source/_serve_range.py 8765
```

Потом в браузере: `http://127.0.0.1:8765/google180.html?square&clean&s=1` (`s=N` — номер слайда, стрелки ←/→ листают).

## Где что лежит

| Что | Где |
|---|---|
| Тексты, порядок и оформление слайдов | `source/overrides.json` (руками не править — через скрипты ниже) |
| Собранные данные деки | `js/slides-google180.js` (генерируется) |
| Стили новых слайдов | `css/rest-1006.css`, `css/block-154-163.css` |
| Картинки и видео | `assets/` |
| Шпаргалка по правкам | `EDIT-CHEATSHEET.md` |

## Как править

Проще всего — открыть папку в Claude Code и попросить: «прочитай EDIT-CHEATSHEET.md и поменяй на слайде N …». Шпаргалка описывает все команды.

Вручную:

```bash
python3 source/_slide.py 184                                  # что на слайде 184
python3 source/_edit.py 184 --t "Новый <em>заголовок</em>" --reason "правка" --shot   # заменить заголовок, собрать, сделать скрин
```

После правки CSS/JS — поднять `?v=` в `index.html` и `google180.html` (или `_edit.py … --bump`).

## Выкладка

`zsh source/_deploy_1001.sh` — собирает чистую копию и выкладывает на Vercel (нужен доступ к проекту `yasko-preza-1001`).

## Архив: описание версии v5 (22.09.2026)

### AI-Оператор · преза эфира · v5 «ЭФИР»

Интерактивная HTML-презентация для вебинара Влада Яско «Как заработать первые $1.000 на AI в 2026» (реалити-шоу AI-агентов).
305 слайдов / 234 в версии на 60 мин, 8 актов, дофаминовая кривая. Без сборки: открывается как статика.

- Прод-превью: https://yasko-preza-v5.vercel.app (проект Vercel `yasko-preza-v5`, команда myroslavnahirniaks-projects)
- Локально: `python3 -m http.server 8765` из этой папки → http://localhost:8765

#### Структура

```
index.html        оболочка (stage, HUD, режиссёрская панель)
css/deck.css      дизайн-система: aurora-фон, цвет акта × уровень кривой, все компоненты
js/slides.js      ДАННЫЕ слайдов (S), акты (ACTS), режиссёрские карточки (DIR), CTA_URL
js/deck.js        движок: рендер, навигация, чат-печать, видео-биты, стек, частицы, панель
assets/           фото/видео/мемы Влада (перенесены из v3), шрифты (woff2), vendor
source/           исходники v3 (html/css/js/json), транскрипты Tella, экспорт Google Slides — НЕ деплоится
shots/            скриншоты для согласования; _cdp_shots.mjs — рендер всех слайдов одним headless Chrome (QA)
source/gslides-vs-html.md — отчёт расхождений Google Slides ↔ HTML (тексты, которые есть только в одном из источников)
```

#### Клавиши (совпадают с v3 + новое)

→ / пробел / клик / PgDn — вперёд (стек и видео — по одной мысли) · ← / PgUp — назад · Home / End
F — полный экран · W — 16:9 ⇄ квадрат (квадрат по умолчанию: рядом видео спикера)
N — заметки спикера · D — режиссёрская панель + дофаминовая кривая · E — полоса уровня
M — версия 60 мин · S — к следующему слайду с пометкой · P — пауза видео · V — звук видео (кружок играет со звуком)
цифры + Enter — прыжок к слайду · ? — подсказка

URL: `?s=58` (слайд) · `?mvp` (60 мин) · `?wide` (16:9) · `?draft` (панель) · `?clean` (без HUD)

#### Как править контент

Все тексты — в `js/slides.js` (массив `S`, порядок = порядок слайдов). Поля слайда:
`a` акт · `lv` уровень кривой 1–10 · `mvp` входит в 60-мин · `kind` hero|text|screen|video|meme|embed|stack|price|cta|qa
`k` кикер · `t` заголовок (html) · `b` тело (html) · `note` заметка · `st` [статус, комментарий]
`bg` + `bgside:'side'` фото-сплит · `photos` сетка фото · `lost` обесцветить · `src/poster/beats` видео с битами
`img/ar/caps/bar` мем · `rows` стек · `cta` текст кнопки · `fx` спецэффект нового движка

Ссылка брони: `window.CTA_URL` в начале `js/slides.js` (сейчас плейсхолдер `#ОПЛАТА`).

#### Дизайн-система (коротко)

- Фон «aurora»: цвет задаёт акт (мята → янтарь → фиолет → циан → оранж → розовый → золото → свет),
  яркость и энергия частиц — уровень дофаминовой кривой `lv`; при `lv ≤ 3` палитра холодная, фото обесцвечены.
- Шрифты: Unbounded (заголовки, пословный reveal), Manrope (текст), JetBrains Mono (техметки).
- Размеры в `cqh` от высоты холста → квадрат и 16:9 выглядят одинаково по пропорциям.
- Медиа грузятся лениво (±3 слайда), видео стартует при показе, вертикальные видео — в рамке телефона.
